# SD 卡素材

FAT32 根目录短文件名：
- PHOTO1.BMP、PHOTO2.BMP、PHOTO3.BMP、PHOTO4.BMP。
- AUDIO1.WAV、AUDIO2.WAV、AUDIO3.WAV、AUDIO4.WAV。
- BGM.WAV。

BMP：24 位未压缩，宽 1–1024、高 1–2048；按 BMP 头读取像素偏移，保留标准行填充。
旁白 WAV：标准 PCM、48 kHz、16 位、单声道。读取器检查标准 WAV 头。
BGM 使用专用读取路径；当前目录扫描要求文件总大小恰为 4,848,044 字节。任意歌曲不能直接替换；需核对采样格式、长度和循环边界。更换固件参数时须另行验证。

外部照片、旁白、音乐不随源码提供。内置 MIF 是构建输入，不可当作缓存删除；其素材来源、许可和转换流程待补齐。
